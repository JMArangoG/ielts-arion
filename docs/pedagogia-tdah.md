# Pedagogía autogestionada para adultos con TDAH

Decisiones de diseño (justificación breve):
1. Sesiones de 5–15 min (microaprendizaje): reduce fricción de inicio y fatiga ejecutiva.
2. Recuperación activa + repaso espaciado (SRS): memoria durable con menos tiempo total.
3. Progreso visible y metas mínimas: motivación saludable, sin rachas punitivas.
4. Pausas programadas y modo concentración: autorregulación atencional.
5. El error es dato, no castigo: el motor adaptativo recalibra la dificultad.
6. Baja carga visual y lenguaje claro (ARION): accesibilidad cognitiva (WCAG 2.2).

Base andragógica: aprendizaje autogestionado orientado a adultos (Knowles).
La app no sustituye acompañamiento clínico ni terapéutico.
